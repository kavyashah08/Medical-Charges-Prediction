# Medical Insurance Charges Prediction

A beginner Machine Learning project that predicts medical insurance charges based on personal and lifestyle factors such as age, BMI, smoking status, gender, number of children, and region.

## 🚀 Features
- Data Cleaning & Preprocessing
- Categorical Feature Encoding
- Random Forest Regression
- Hyperparameter Tuning using RandomizedSearchCV
- Model Evaluation using R² Score
- Model Saving with Joblib

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Joblib
- Jupyter Notebook

## 📊 Dataset Features
- Age
- Gender
- BMI
- Children
- Smoker Status
- Region

**Target Variable:** `charges`

## 🤖 Model
Random Forest Regressor with hyperparameter tuning for improved performance.

## 📈 Evaluation Metric
- R² Score
